# Open Peeps avatars

Source artwork: Open Peeps by Pablo Stanley, https://www.openpeeps.com/
License: CC0 1.0 Universal, https://creativecommons.org/publicdomain/zero/1.0/

These 24 static SVGs were exported using DiceBear's Open Peeps style (10.x):
https://www.dicebear.com/styles/open-peeps/
https://www.dicebear.com/licenses/

Seeds: CozyHealth-1 through CozyHealth-24. Background colors alternate between
edf4ff, ecf9f0, fff3e9, and fff9df. Exported 2026-10-15. The generated artwork is
bundled locally; no user identity or image is sent to DiceBear at runtime.
SVG metadata elements were removed for Flutter SVG renderer compatibility; the
illustrations are otherwise unchanged.
